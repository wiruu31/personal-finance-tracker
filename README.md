# Personal Finance Tracker

Web app sederhana untuk memantau kondisi keuangan pribadi: net worth, aset, utang, dan target keuangan.

## ✨ Fitur
- Ringkasan net worth
- Pencatatan aset dan utang
- Target (goals) keuangan
- Grafik donat untuk melihat komposisi keuangan
- Tema hijau

## 🛠️ Tech Stack
HTML · CSS · JavaScript

## 🚀 Cara Menjalankan
1. Clone repo ini
2. Buka `index.html` di browser

> Data disimpan di localStorage browser, jadi tidak terkirim ke server.
